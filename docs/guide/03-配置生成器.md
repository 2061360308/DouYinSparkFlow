# 配置生成器

配置生成器用来生成 `.env` 配置文件（含账号、目标好友、登录 Cookie、定时参数等）。

## 推荐：本地 configTool

从 [Release](https://github.com/2061360308/DouYinSparkFlow/releases) 下载 `DouyinSparkFlow-configTool-win-x64.zip`，解压后运行 exe。

优点：

- **自动抓取登录态**：内置隐身浏览器，扫码 / 短信登录后自动抓取 Cookie，无需手动导出
- 自动抓取会话列表，直接点选目标好友
- 支持「配套代理」隧道，保证抓 Cookie 的出口与任务运行出口一致（见 [Cookie 与出口 IP](guide/02-cookie与出口IP.md)）

用法详见 [服务器 Docker](deploy/docker.md) 里的配置步骤。

## 兼容：网页配置生成器

在线网页版：[https://2061360308.github.io/DouYinSparkFlow/generator/](https://2061360308.github.io/DouYinSparkFlow/generator/)（若绑定了自定义域名，则为 `你的域名/generator/`）

优点：在线即用，无需下载安装。

缺点：

- **不能自动抓 Cookie**：网页无法读取本地浏览器数据，需要你自己用 Cookie-Editor 等扩展手动导出 JSON 并粘贴
- **出口 IP 要自己想办法对齐**：网页生成的 Cookie 是你本机 IP 抓的，而定时脚本跑在别处，出口 IP 不一致会导致登录态掉（见 [Cookie 与出口 IP](guide/02-cookie与出口IP.md)）

所以网页版只作为「没有 Windows、又只想快速拼一份配置」的兼容选项，正式使用仍推荐 configTool。

## 配置项说明

| 名称 | 作用解释 | 期望值 | 获取方法 |
| --- | --- | --- | --- |
| 代理地址 | 写进 `.env` 交给任务运行时用（不是给 configTool 自己用的） | 留空或用配套代理 | 按需填写 |
| 执行时间 | 仅 Docker 部署有效，拆成 CRON_HOUR / MINUTE / SECOND | 如 `09:00:00` | 按需填写 |
| 时区 | 容器时区 | `Asia/Shanghai` | 默认即可 |
| 消息模板 | 发送的消息，`[API]` 会替换为每日一言 | 用 `\n` 表示换行 | 从抖音聊天框编辑好后复制 |
| 一言类型 | 每日一言允许的类型 | 勾选即可 | 按需勾选 |
| 浏览器操作最长等待时间 | 单次导航 / 点击的等待上限 | 默认即可，网络慢可调大 | 基本无需改 |
| 扫描总预算 | 超时即停，未找到不代表不存在 | 默认即可 | 基本无需改 |
| 门禁等待上限 | 登录校验 + 会话列表就绪的等待上限 | 默认即可 | 基本无需改 |
| 好友列表等待时间 | 发现新会话后等资料落定的时长 | 默认即可，网络慢可调大 | 基本无需改 |
| 滚动步数上限 | 步长 = 可视高度 40% | 默认即可 | 基本无需改 |
| 任务重试次数 | 任务失败重试次数 | 默认即可 | 基本无需改 |
| 输出日志级别 | Error < Warning < Info < Debug，越小输出越少 | `Info`，排查时用 `Debug` | 按需选择 |
| 用户名 | 账号标识，仅用于日志 | 随意填写 | 登录后自动抓取 |
| 抖音号 | 账号的抖音号，决定 `.env` 里的 COOKIES 键名 | 必填 | 登录后自动抓取 |
| Cookies | 账号登录态 | 登录后自动抓取 | configTool 自动抓，网页版手动导出 |
| 目标好友 | 要续火花的好友 | 备注 / 昵称 / 抖音号 | configTool 拉取会话列表点选 |
