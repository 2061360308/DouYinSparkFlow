# DouYin Spark Flow

DouYin Spark Flow 是一个面向个人与小型团队的抖音火花自动续火项目。项目通过浏览器自动化完成账号登录、好友选择和定时消息发送，并提供可视化控制台统一管理账号、任务与执行记录。

> 本项目仅用于技术研究与个人自用。使用者应遵守抖音平台规则及相关法律法规，合理控制任务频率。

## 项目能力

### 多用户控制台

- 支持管理员与普通用户两类角色。
- 普通用户可通过邀请码注册并维护自己的账号与任务。
- 管理员可生成和管理邀请码、查看用户及任务状态，并暂停或删除任务。
- 用户数据相互隔离，每位用户只能管理自己名下的抖音账号和续火任务。

### 抖音账号管理

- 通过浏览器登录流程绑定抖音账号。
- 支持短信验证码等额外身份验证步骤。
- 登录状态加密保存，页面不会再次展示完整凭证。
- 可读取当前账号可见的聊天会话，并通过搜索列表选择目标好友。
- 保留手动填写好友名称的方式作为兼容方案。

### 定时续火任务

- 为不同账号分别设置目标好友、发送时间和消息内容。
- 支持多个账号、多个目标和多条独立任务。
- 可暂停、恢复或删除任务。
- 调度器具备启动宽限和有限重试机制，可应对短暂重启或发送前的网络波动。
- 消息提交与页面二次确认分开记录，减少状态误报和重复发送风险。

### 执行记录

- 保存每次计划执行的开始时间、完成时间、执行阶段和结果。
- 区分成功、已提交、失败、跳过等状态。
- 错误信息经过收敛处理，不在页面中暴露登录凭证或敏感运行数据。
- 用户可查看自己的任务历史，管理员可查看全局任务概况。

### 多种运行方式

- Web 控制台适合长期管理多个账号和定时任务。
- 保留脚本运行方式，便于个人本地使用和自动化工作流调用。
- 支持容器化运行，方便将 Web、登录流程和任务执行器分离管理。

## 技术架构

| 模块 | 作用 |
| --- | --- |
| FastAPI Web | 用户注册、账号管理、任务配置、执行记录和管理员后台 |
| Auth Worker | 驱动浏览器登录流程并保存加密后的登录状态 |
| Spark Worker | 领取到期任务、执行消息发送并写入执行结果 |
| Playwright | 操作抖音网页聊天和登录页面 |
| SQLite / SQLAlchemy | 保存用户、账号、任务、邀请码和执行历史 |
| Docker Compose | 组织控制台、登录服务和任务执行器 |

## 工作流程

1. 管理员创建邀请码，用户完成注册并登录控制台。
2. 用户绑定自己的抖音账号，系统加密保存登录状态并读取可见会话。
3. 用户选择目标好友，设置发送时间和消息内容，创建续火任务。
4. 任务执行器按计划发送消息，并将实际执行阶段和结果写入历史记录。

## 安全说明

- 不要将 Cookie、Token、密码、私钥或包含登录状态的文件提交到代码仓库。
- 登录凭证具有账号访问权限，应仅保存在可信环境中。
- 浏览器自动化依赖目标页面结构，抖音页面更新或风控验证可能影响任务执行。
- 建议先使用测试账号和测试任务确认流程，再用于日常续火。
