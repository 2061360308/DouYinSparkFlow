# 项目介绍

DouYinSparkFlow 是一个抖音火花自动续火脚本：通过无头浏览器模拟人工操作，定时登录抖音网页版聊天页，给指定的好友发送消息来续火花。

## 特性

- **多账号**：同时批量管理多个抖音账号
- **多目标**：一个账号可以给多个好友续火花
- **智能匹配**：支持按备注 / 昵称 / 抖音号匹配目标好友
- **一言消息**：支持「每日一言」模板，消息内容更丰富
- **可视化操作**：自动抓取登录态、生成配置，新手也能操作
- **隐身浏览器**：内置 cloakbrowser 隐身 Chromium，可固定指纹，伪装系统环境等，降低被识别为机器的风险
- **字体指纹补全**：预置 Windows 默认字体（Segoe UI / 微软雅黑 / 宋体等），让 Linux 上实际可检测的字体集与 Windows 伪装身份自洽，规避字体指纹检测
- **出口 IP 对齐**：配套 gost 隧道，保证「抓 Cookie 的出口」与「跑任务的出口」一致，登录态不易掉

## 运行原理

项目用 cloakbrowser（底层 Playwright）驱动无头 Chromium，自动化操作抖音网页聊天版（https://www.douyin.com/chat ），在配置的时间点给目标好友发送续火消息。
