# 配置生成器

配置生成器用来生成 `.env` 配置文件（含账号、目标好友、登录 Cookie、定时参数等）。

## 推荐：本地 app

从 [Release](https://github.com/2061360308/DouYinSparkFlow/releases) 下载 `DouyinSparkFlow-win-x64.zip`，解压后运行 exe。

优点：

- **自动抓取登录态**：内置隐身浏览器，扫码 / 短信登录后自动抓取 Cookie，无需手动导出
- 自动抓取会话列表，直接点选目标好友
- 支持「配套代理」隧道，保证抓 Cookie 的出口与任务运行出口一致（见 [Cookie 与出口 IP](guide/02-cookie与出口IP.md)）

用法详见 [服务器 Docker](deploy/docker.md) 里的配置步骤。
