# AI 陪聊

陪聊独立于原有续火花任务。启动后持续观察选定好友和群聊的会话，只回复启动之后的新文字消息。

## 本机使用

1. 打开应用，在「账户配置」登录抖音，拉取会话列表。
2. 打开「AI 陪聊」。默认服务为 DeepSeek，填写自己的 API Key。默认地址为 `https://api.deepseek.com`，模型为 `deepseek-flash`，也可自行修改。
3. 点击「测试 API」，查看连接结果。这一步只发送固定测试问候，不向抖音好友发送消息。
4. 在每个账号下面选择陪聊好友或群名。该名单与续火花好友名单独立；不会自动勾选任何人。
5. 调整角色提示词、上下文轮数、轮询间隔和回复间隔，点击「启动陪聊」。
6. 点击「停止陪聊」或关闭应用结束。正在生成的回复会在停止后被丢弃；正在进行的网络请求和浏览器检查结束后资源会释放。

修改配置后需停止并重新启动。界面显示当前会话的连接、回复结果和异常次数，不显示聊天正文。

## 添加其他 AI 服务

点击「添加服务」，选择「OpenAI 兼容接口」，填写服务名称、API 地址、模型和 API Key，然后在「当前服务」选择它。服务地址应是 API 基础地址，例如 `https://example.com/v1`，不要填写到 `/chat/completions`。

可以保存多个服务并切换。当前所有账号共享选中的服务和角色提示词。DeepSeek 使用 OpenAI SDK 的 Chat Completions 协议，默认关闭思考模式以减少陪聊等待时间。

开发新的非兼容协议时，实现 `reply(messages) -> str` 和 `close()`，通过 `core.ai.providers.register_provider(kind, factory)` 注册；回复引擎无需修改。

## 命令行

```powershell
.\.venv\Scripts\python.exe main.py chat
```

从 `.env` 加载与界面相同的配置，持续运行，按 Ctrl+C 停止。原来的 `main.py task` 仍只跑一轮续火花。

`AI_CHAT` 保存完整 AI 配置的单行 JSON；`TASKS` 每个账号新增 `ai_targets` 数组。例如：

```json
{"username":"示例账号","unique_id":"example","targets":["续火花好友"],"ai_targets":["陪聊好友抖音号"]}
```

已有旧配置缺少 `ai_targets` 时默认为空，不会自动启动陪聊。API Key 保存在本机被 Git 忽略的 `.env`，不要提交它。概览和复制配置会隐藏 API Key，迁移到其他环境需要重新填写。

## 行为与边界

- 支持文字私聊和群聊，跳过图片、表情、视频和陌生人/折叠会话。好友昵称或群名必须精确匹配；重名时用会话 ID，好友也可用抖音号或 UID。
- 好友消息及本次陪聊上下文会发送到所选 AI 服务；不向模型发送 Cookie 或账号配置。
- 群聊默认回复所选群内启动后的新文字消息，无需 @；连续消息合并成一条回复，并沿用配置的回复间隔。不会自动选择其他群。
- 群消息使用本次运行内固定的成员标签，区分不同发言者；成员 UID 不发送给模型。无法识别发送者时标为「未识别成员」。
- 上下文在内存中按账号和会话隔离，并限制轮数；停止/重启后清空，不持久化聊天正文。
- 同一好友连续新消息会合并生成一条回复。历史消息和自己的消息不回复；检测到手动回复后不再补发。
- API 失败会退避 60 秒重试；发送没有明确回执时不自动重发，避免重复回复。
- 页面使用虚拟消息列表，只能读取当前渲染的文字消息；大量消息或很多好友时可能漏掉已滚出窗口的消息。轮询切换会话也会改变网页未读状态。
- 陪聊需要程序持续运行，当前不自动注册常驻服务、开机任务或云函数触发器。与同账号的续火花任务同时运行时，两者仍可能分别发送消息。

接口与模型参考：[DeepSeek 官方首次调用文档](https://api-docs.deepseek.com/zh-cn/)。
