# 讨论与贡献

## 提问与反馈

有疑问、报 Bug、提需求，优先到 GitHub Discussions：

- [讨论区](https://github.com/2061360308/DouYinSparkFlow/discussions)

请先在讨论区搜索是否已有相同问题，避免重复发帖。描述问题时尽量带上：部署方式、日志（`logs/` 目录）、复现步骤。

## 欢迎贡献

欢迎提交 PR。流程如下：

1. Fork 本仓库
2. 基于 `dev` 分支创建你的功能分支
3. 修改后提交，推送到你的 Fork
4. 发起 Pull Request

提交前请保证本地测试通过：

```bash
python -m unittest discover -s tests -t .
```
