# 好友聊天记录导出

1. 在「账户配置」找到已登录的账号。首次导出前点「刷新登录信息」，保存账号身份。
2. 点「拉取会话列表」，随后在「导出好友聊天记录」选择好友。也可以输入好友抖音号或会话 ID；同名会话不会自动任选一人。
3. 点「导出 TXT + JSON」。程序在后台打开好友会话，逐屏向上加载，按消息 ID 去重，最后按时间排列。
4. 完成后查看消息数量、时间范围和停止原因，点「打开导出目录」取文件。中途可点「停止并保存已读记录」。

文件保存在程序数据目录的 `chat_exports/` 下，每次创建独立子目录，包含一份 TXT 和一份 JSON。源码运行时默认位于 `app/chat_exports/`；设置 `APP_DATA_DIR` 后随数据目录移动。TXT 方便阅读，JSON 保留消息 ID、发送者、原始时间戳与会话内顺序。显示时间使用北京时间（UTC+8）。

当前支持网页版可加载的**文字消息**。图片、语音、视频、已撤回或已删除的消息不在导出范围内。页面顶部持续无新增、滚动停滞、读取异常、到达 15 分钟时限或用户停止都会结束导出；有已读文字时保留这些内容。页面无新增不代表服务器没有更早记录，因此结果始终注明「未确认全部历史」。

浏览器打开会话可能改变未读状态。导出文件留在本地，包含聊天内容，请按需要保管。导出不会调用 AI 服务，也不会发送聊天消息。
